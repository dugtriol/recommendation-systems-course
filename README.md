## Задание 1. Коллаборативная фильтрация (ALS)

Было выполнено обучение ALS-модели с учётом весов взаимодействий (просмотр, лайк, дизлайк и т.д.) с использованием библиотеки `implicit`.

**Данные:**  
- `train.parquet` – история действий пользователей (user_id, item_id, weight, timestamp)  
- `test.parquet` – пары (user, item) для предсказания

**Выполненные шаги:**  
1. Произведена загрузка тренировочных данных и создание CSR-матрицы `user × item` с заполнением ячеек значениями `weight`.  
2. Осуществлено обучение ALS с параметрами: `factors=64`, `regularization=0.05`, `iterations=15`.  
3. Для каждого пользователя из тестового набора:  
   - выполнено исключение из кандидатов уже просмотренных / оценённых им товаров  
   - произведён расчёт предсказанных рейтингов через `model.recommend()`  
   - отобраны топ-10 элементов  
4. Результат сохранён в `submission.csv` (колонки: user_id, item_id).  

Дополнительно реализован простой бейслайн **Top-Popular** (`solution_toppop.py`) – осуществляется рекомендация самых частотных элементов без персонализации.

**Результат:**  
Сгенерированы рекомендации для всех пользователей из тестовой выборки.

## Задание 2. BPR (Bayesian Personalized Ranking)

**Что было выполнено:**  
Построена pairwise ранжирующая модель BPR, предсказывающая относительный порядок элементов для каждого пользователя.

**Данные:**  
- `train.parquet` – история взаимодействий (все положительные взаимодействия)  
- `test.parquet` – пары для оценки  
- `user_metadata.parquet`, `item_metadata.parquet`, `item_embeddings.parquet` – дополнительные данные (не использовались в базовом решении, но могут быть применены для контентных признаков)

**Выполненные шаги:**  
1. Из `train.parquet` были отфильтрованы только положительные взаимодействия (вес > 0). Построена бинарная матрица `user-item`.  
2. Выполнено обучение BPR (`implicit.bpr.BayesianPersonalizedRanking`) с настройками:  
   - `factors = 64`  
   - `learning_rate = 0.01`  
   - `iterations = 50`  
3. Генерация рекомендаций: для каждого пользователя получены 10 лучших элементов, не встречавшихся в обучении (исключение выполнено через фильтр).  
4. Результат сохранён в `submission.csv`.

Вспомогательный файл `solution_classifier.py` демонстрирует альтернативный подход – на основе эмбеддингов элементов и логистической регрессии, однако основное решение выполнено через BPR.

**Результат:**  
Получен файл с персонализированными рекомендациями для тестовой выборки.
